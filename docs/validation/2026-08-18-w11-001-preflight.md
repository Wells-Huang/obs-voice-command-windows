## Implemented probe contract

[tools/inspect_obs_contract.py](../../tools/inspect_obs_contract.py) is dependency-lazy and read-only. It performs:

1. A bounded TCP check before importing obsws-python.
2. Local OBS executable/process detection when the endpoint is unreachable.
3. GetVersion, GetCurrentProgramScene, GetSceneItemList, GetInputSettings, and GetSceneItemTransform only after the endpoint is reachable.
4. Validation of obs-websocket 5.x, capture input kind, Windows monitor_id when the kind is monitor_capture, and positive numeric transform fields.
5. Sanitized JSON evidence. Scene/source names are represented by labels and short digests; monitor IDs are represented as presence plus a short digest; credential-like fields and exception fragments are redacted. The WebSocket password is accepted only from an environment variable or TOML config and is never printed or persisted.

Status values and exit codes are stable:

| Status | Exit | Meaning |
| --- | ---: | --- |
| SUCCESS | 0 | Read-only transform contract verified. |
| MISSING_OBS | 2 | Endpoint unreachable and OBS was not detected. |
| UNREACHABLE_ENDPOINT | 3 | OBS may be installed/running, but the endpoint cannot be reached. |
| PROTOCOL_API_MISMATCH | 4 | TCP is reachable, but the WebSocket/API response is incompatible or unusable. |
| TRANSFORM_CONTRACT_FAILED | 5 | OBS responded, but source selection, monitor_id, or transform fields do not satisfy the contract. |
| PROBE_DEPENDENCY_MISSING | 6 | Endpoint is reachable but obsws-python is absent from the active environment. |

The probe does not call any mutating request such as SetSceneItemTransform.
